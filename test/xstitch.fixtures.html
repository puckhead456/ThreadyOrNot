XStitch.js fixture run (dev only - loads copyrighted charts from ../tmp-pdf at runtime; nothing here is committed)

Put chart PDFs in tmp-pdf/xs-<name>.pdf; they are read with PdfText.extract here and the text is cached in sessionStorage, so only the first run of each file is slow. A hand-made tmp-pdf/xs-<name>.txt overrides the PDF. OXS exports go in tmp-pdf/xs-<name>.oxs. tmp-pdf/ is gitignored; never commit a purchased or downloaded chart. Missing fixtures are skipped, so this page stays green on a clean checkout.

Heavy fixtures: anything over 20 MB (the two big Antique Pattern Library scans) is skipped unless you load this page as xstitch.fixtures.html?heavy=1, so the default run stays around a minute. The grid reader is given a 5 second budget on every fixture here, which is the "a scan must fail fast" case.
